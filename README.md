# 에너지 레벨 감지기

에너지를 실제보다 높게 어림잡고 무리하다 뻗는 패턴을 막으려고 만든 1분 점검 앱입니다.
**느낌으로 잰 에너지**와 **몸·마음 신호로 잰 에너지**를 한 눈금에 나란히 보여 주고, 둘 중 낮은 쪽에 맞춰 오늘 계획 크기를 정해 줍니다.

- 앱 열기: https://claude.ai/artifact/LBAuKMrZJCN8rJCEz6Zh85 (claude.ai에 로그인한 브라우저에서 열려요)
- 휴대폰에서는 브라우저 메뉴의 "홈 화면에 추가"로 앱처럼 쓸 수 있어요.

## 쓰는 법

| 언제 | 무엇을 |
|---|---|
| 아침 | "오늘 체크 시작" → 느낌 점수 → 잠과 부하 → 몸·마음 경고등 → 브레이크 점검 → 결과 |
| 하던 일 중간 | "지금 멈춰야 할까?"에서 해당하는 것만 눌러 보기 (저장 안 함) |
| 다음 날 | "어제는 어땠어요?"에 한 번 누르기 (여유 · 딱 맞음 · 무리 · 뻗음). 체크하고 결과를 안 남긴 지난 며칠(3일까지)도 차례로 물어요 |

결과가 쌓이면 "기록"에서 내 느낌이 신호보다 평균 몇 점 높게 나오는지, 무리하거나 뻗은 날 아침에는 어땠는지 보여 줍니다.

## 점수 계산

10점에서 시작해서 고른 항목마다 깎습니다. 0~10점이고, 느낌을 높게 잡지 않도록 0.5점 단위로 내림합니다 (예: 9.25 → 9).

| 항목 | 깎는 점수 |
|---|---|
| 어젯밤 잔 시간: 5시간 미만 / 5~6시간 / 6~7시간 / 7시간 이상 | −3 / −2 / −1 / 0 |
| 일어났을 때: 개운 / 보통 / 찌뿌둥 / 거의 못 잠 | 0 / −0.5 / −1 / −2 |
| 지난 3일 중 무리한 날: 0 / 1 / 2 / 3일 | 0 / −0.5 / −1.5 / −2.5 |
| 오늘 지금까지 쓴 에너지 (낮 12시 이후나 그날 두 번째 체크부터): 거의 안 씀 / 조금 / 꽤 / 많이 | 0 / −0.5 / −1 / −2 |
| 새벽 1시 넘어서 잤다 | −0.5 |
| 어제 사람을 많이 만났다 · 어제 멀리 다녀왔다 | 각 −1 |
| 몸 경고등 4개 · 마음 경고등 4개 | 하나마다 −0.5 |
| 브레이크 세 기준: 동기(불안·조급함이 연료) · 제어(멈추려 해도 안 멈춰짐) · 감각(일상이 무채색) | 하나마다 −0.75 |
| 느낌을 부풀리는 것: 들떠 있다 · 다 할 수 있을 것 같다 | 0 (과대평가 위험만 표시) |
| 느낌을 부풀리는 것: 끈기로 밀어붙이는 중 · 커피로 버티는 중 | 하나마다 −0.5 |

- 구간: 8~10 충분 · 6~7.5 보통 · 4~5.5 낮음 · 0~3.5 바닥
- 오늘 계획 크기는 느낌과 신호 중 **낮은 쪽**에 맞춥니다. 충분: 큰 일 3개까지 / 보통: 2개까지 / 낮음: 1개 + 작은 일 / 바닥: 꼭 해야 할 일 1개만
- 브레이크 세 기준 중 하나라도 켜지거나 신호가 3.5 이하면 "멈춤 → 회복 → 복귀"를 안내합니다.
- 하루는 새벽 6시에 바뀝니다. 새벽 2시에 한 체크는 전날 기록이 됩니다.
- 처음 기준은 대략적입니다. 기록이 쌓이면 실제로 뻗은 날에 맞춰 고쳐 갑니다.
